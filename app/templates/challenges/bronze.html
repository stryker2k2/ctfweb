In this Bronze Challenge, we will create a simple program using the C Language using functions that are known to be vulnerable to Buffer Overflows.




Create Vulnerable Executable

Launch VS Code

Visual Studio Code is installed on the Lubuntu Laptops provided. Find it on the Desktop and Double Click to Open. If prompted, select "Execute".



Install VS Code (if not available)

To install VS Code on your own personal machine, copy & paste the following into your Ubuntu Terminal

        sudo snap install code --classic

Open Desktop Folder inside VS Code

Click on the File Icon

Click "Open Folder"

Click "repo"

Click "Open"



Create a New File

Right Click in the Left Pane

Click "New File"

Name it "bronze.c"



Create Vulnerable Code

Copy the Code to the right into the "bronze.c" file



Review Vulnerable Functions

The function sprintf is the vulnerable function. According to Microsoft,

"the sprintf function formats and stores a series of characters and values in buffer."

But it does not provide say that this function is capable of error correction or size protection. We are going to use this flaw to wreck the program and force it to perform a different non-planned tasked.

{{ markdown_content|safe }}


Compile Code into a 32-bit Executable

We will be compiling this program as a 32-bit Executable using the GNU Compiler Collection. This is a popular set of compilers for various programming languages.

Open a Terminal by going to VIEW > TERMINAL

Run the following command

        gcc -m32 -no-pie -O0 -Wno-format-truncation -fno-stack-protector bronze.c -o bronze



Review the Compilation Command

Let's break down the command we just passed


gcc - The GNU Compiler for C Language

-m32 - 32 Bit Application

-no-pie - Disables Position-Independent Executable

-O0 - No Optimization

-Wno-format-truncation - Disables Format Truncation Warnings

-fno-stack-protector - Disable Stack Smash Protection

bronze.c - The File to be Compiled

-o bronze - Output Name of the Compiled Executable




Install GCC (if missing)

The provided laptops have GCC and the 32-bit Libraries required. To install these onto your personal laptops, use the following commands.

        sudo apt install build-essential libc6-dev-i386 -y

Running the Executable as Intended

We coded this program to accept one parameter through the command line and save that parameter to a log. Run the program as intended and monitor the log file.

./bronze "Hello World!"

cat log.txt



Runing the Executable Incorrectly and Perform Buffer Overflow

Any parameter we input that is under the size limit of 64 bytes (characters) will work as intended. But, if we pass in a parameter more than 64 bytes (characters), the program will save all of the characters to memory; even if the parameter is more than 64 bytes. We will notice that the program will crash and provide us with a "Segmentation Fault".


./bronze "AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA"

cat log.txt

Install Ghidra (if not available)

To install Ghidra on your own personal machine, copy & paste the following into your Ubuntu Terminal

        wget -O - https://apt.corretto.aws/corretto.key | sudo gpg --dearmor -o /usr/share/keyrings/corretto-keyring.gpg && echo "deb [signed-by=/usr/share/keyrings/corretto-keyring.gpg] https://apt.corretto.aws stable main" | sudo tee /etc/apt/sources.list.d/corretto.list

        sudo apt-get update; sudo apt-get install -y java-21-amazon-corretto-jdk; wget https://github.com/NationalSecurityAgency/ghidra/releases/download/Ghidra_11.4.2_build/ghidra_11.4.2_PUBLIC_20250826.zip -O /tmp/ghidra.zip; unzip /tmp/ghidra.zip -d ~/Tools/

        ln -s /home/$USER/Tools/ghidra_11.4.2_PUBLIC/ghidraRun /home/$USER/Desktop/ghidra
